# Lire les sichot

Application web (français) pour apprendre à lire et comprendre les sichot du Rabbi de Loubavitch en hébreu : parcours de 28 jours, lecteur hébreu avec aides progressives, révision espacée, bilans hebdomadaires et fiches imprimables.

Site : https://amzingfba.github.io/lire-les-sichot/

Textes : Sefer HaSichot 5748 (Vayichla'h, p. 151-154) et Torat Menachem – Hitvaaduyot (5711, 5717, 5718, 5719), d'après les documents liés par l'index Mafteiach. Chaque texte affiche sa source, sa page et son mode de vérification dans l'application.
